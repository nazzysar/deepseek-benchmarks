    How to Read a Lying Atlas

    Deduce the entire map and the exact set of lies.

    The task. Ink a terrain into every hex: Sea, Forest, Mountain, Desert and Swamp (tiers use the first three, four or five). The cartographer supplies notes, but is unreliable: exactly L notes lie, L shown in the liar counter. Every other note must be true. Mark exactly L notes as lies and proclaim a map that satisfies the whole ledger.

    Rows are defined by equal axial r; row lengths shrink toward the map's north and south edges. Axial neighbors are the six touching hexes.

    The five note forms

    1 · Neighbour count

    Exactly k of a named hex's six axial neighbours are a terrain.

    2 · Row census

    A row (equal axial r) contains exactly k tiles of a terrain.

    3 · One region

    All tiles of a terrain form one nonempty, edge-connected region. Absent terrain makes this note false.

    4 · Separation

    No two tiles of a terrain touch. A single tile or none at all satisfies it.

    5 · Shared terrain

    Two named hexes hold the same terrain.

    Exactly L notes are false, and a truthful note is satisfied by your map. A configuration is correct only if there is exactly one possible map and liar set — both are part of your answer. If a marked liar is true, or an unmarked note is false, the chart is rejected. The first violation is described for you.

    Using the desk

    • Select a hex on the atlas or in the accessible hex ledger. Choose a terrain from the palette. Click the same terrain again to clear it.
    • Pencil mode toggles candidate glyphs instead of assigning. Pencils are notes to yourself and never affect validation.
    • The lie button on a note plants a wax seal. Exactly L seals are needed.
    • Why? asks the propagation-only solver for the next logically forced deduction, names the supporting notes, and can highlight them on the chart. It never reads the stored solution.
