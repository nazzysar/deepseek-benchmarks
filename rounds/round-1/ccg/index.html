On repeatability

Every chance in the medium is drawn from the seed shown on the plate. A run replayed from the same seed and the same conditions takes the same course — the same births, the same catastrophes, the same drift — at any rate of observation.

On the three orders

Lichenia (flora) holds four genes: growth, fecundity, hardiness, reach. Cervina (grazers) and Noctua (hunters) each carry speed, vision, metabolism, and a reproductive threshold. Children inherit a jittered copy.

On the instruments

Sliders and the rate dial take arrow keys and Home/End. The seed field accepts digits. Every control announces itself on hover or keyboard focus, and changes apply to the living run without a restart.

The simulation is a headless engine; the plate is only its portrait. ?selftest=1 runs its proofs.
