Bench instructions

The rite

Build a dataflow graph from Input to Output. Every tick, each node evaluates once in a deterministic compiler order. A wire holds at most one symbol; a full wire applies backpressure. If nothing changes for two ticks while the output is incomplete, the bench reports a deadlock with stuck wires and blocked nodes.

One wire leaves each output and enters each input. Use Dup to branch a symbol. A compared glyph is <, = or >. Router with a wired COND routes by routeOn; without COND it tests DATA against its threshold.

The compiler schedules nodes by wire dependency (ties by creation order); feedback into Memory DATA/WRITE and Delay IN is relaxed into a register edge.

Mouse & touch

  • Palette: click to add, or drag onto the bench.
  • Drag a node plate to move it; positions snap to the grid.
  • Drag from a round output port to an input port to wire.
  • Click a wire to select it. Delete removes the selection.
  • Right-drag or Space+drag to pan; wheel or ＋/− to zoom. Pan toggle helps touch.

Keyboard

  • Space run/pause · S step · X reset simulation
  • Delete remove selected node/wire · Esc deselect
  • [ / ] cycle node selection · arrows move it by one grid cell
  • T self-tests · ? help · Q quality · M chime
  • P pan mode · +/− zoom · Home camera reset

Two-lane levels

Sort Two requires exactly two Output nodes, lane 0 and lane 1. Both lanes are recorded each tick and interleaved as [lane 0, lane 1]. The inspector edits an Output's lane.

Parentheses use 1 = “(” and 9 = “)”. Sum uses 9 as its sentinel.

Verification

Commit runs this program against the visible streams and 20 hidden streams generated from a fixed seeded PRNG, comparing output symbols and ticks. The T panel runs the pure compiler/VM suite: every reference solution across all visible + hidden cases, deterministic traces, deadlock detection, export/import round-trip, and illegal-wire validation. renderer.info is shown there for the live WebGL renderer.
