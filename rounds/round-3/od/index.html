      The Alchemist's Manual

      controls · semantics · wiring

      Goal

      Build a graph of rune nodes that transforms the input symbol streams into the required output stream. Every tick is synchronous: each node may fire once, each wire carries at most one rune, and full downstream wires block upstream nodes (backpressure). Validate against the visible trials and 20 sealed hidden trials.

      VM rules

      Deterministic evaluation order is computed from the graph (upstream first, ties by node order). Cycles must pass through a stateful node (Delay, Memory, Counter). Inputs release one rune per stream per tick (parallel levels) or one rune from the active stream (single). Deadlock is reported after two consecutive ticks with no state change while output is incomplete. A run ends after two quiescent ticks with all inputs consumed and the expected output length reached.

      Symbols

      0–9 are rune values. Compare emits < = > as control glyphs. Add/Sub wrap modulo 10. Router routes the DATA rune by the condition. Merge is priority-ordered. Delay holds one rune for one tick. Counter increments modulo its modulus. Memory stores the last WRITE rune and emits its cell on READ.

      Preferences: reduced motion is respected. WebGL pixel ratio is capped at 2. Import/export strings contain only the program — never your browser data.
