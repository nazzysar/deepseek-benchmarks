The Compiler's Primer

Keyboard operation, wiring rules and rune semantics

Keyboard map

  • Tab moves through palette, roster, ports and controls. Enter activates.
  • R run · P pause · S step · 0 reset view
  • T self-tests · H / ? help · I import/export
  • Arrow keys nudge the selected node on the grid.
  • W starts a wire from the selected node's first free output.
  • Choose an output port in the Inspector, then an input port, for keyboard wiring.
  • Delete removes the selected node or wire · Esc cancels a wire.

Camera

  • Wheel or +/− zooms.
  • Alt-drag, middle-drag or right-drag pans. Two fingers pan and pinch on touch.
  • Drag plates to rearrange. Drag from a brass output port to an input port to wire.

VM laws

  • Every wire holds at most one symbol. Nodes fire synchronously; wires apply backpressure.
  • One output wire per port; use Dup for fan-out. Arithmetic wraps modulo 10.
  • Compare emits 0 (<), 1 (=), 2 (>).
  • Router sends its data left/true when the condition holds, otherwise right/false. Leave control empty to test the data itself.
  • Merge chooses by left/right priority or by lower/upper glyph value. Ties favour A.
  • Counter: count, sum, max, or balance; emit each input or only on the zero sentinel.
  • Memory: W writes, R reads; simultaneous W+R writes then reads.
  • Deadlock fires after two unchanged ticks while output is incomplete.

Scoring

Submit All runs every visible trial and all 20 hidden trials. A passing score records total cycles across trials, node count and wire count. The Pareto chart keeps non-dominated attempts.
