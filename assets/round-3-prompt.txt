Concept
An alchemist's workbench where the player builds a tiny visual program from rune nodes to turn input symbol streams into a required output stream. Think Shenzhen I/O with a mystical look.
Virtual Machine — Implement Exactly
1. Symbols are integers 0–9 shown as glowing glyphs. Nodes: Input, Output, Add, Sub, Compare (emits <, =, > as glyph values), Router (sends left or right by condition), Merge (priority-ordered), Delay (one-tick buffer), Dup, Discard, Counter (stateful), Memory cell (read/write).
2. Synchronous tick execution. Each wire holds at most one symbol; if downstream is full, upstream blocks through backpressure. Define a deterministic evaluation order. Detect deadlock when no state changes for 2 consecutive ticks with outputs incomplete, and report the stuck wires and nodes.
3. Each level provides input streams and an expected output stream, including an interleaving rule. Submissions run against 20 hidden test streams from a seeded PRNG plus the visible ones; all must pass.
4. Score cycles, node count, and wire count. Show a Pareto chart of the player's best attempts.
5. Include 8 levels: pass-through, add pairs, sort 2 values, running maximum, filter evens, balanced-parentheses checker, sum until a sentinel, merge two sorted streams. Include a reference solution per level for self-tests only.
3D Visual Design
- A dark slate bench with etched copper traces. Nodes are extruded brass-framed plates with engraved glyph textures using CanvasTexture and emissive runes that glow when active.
- Wires are TubeGeometry along smooth curves with orthogonal routing and rounded corners. Symbols travel along wires as glowing glyph sprites with light pulses. Blocked wires visibly pressure-pulse red.
- Ambient dust motes using Points, a soft bloom, and a transmutation particle burst with a chime-style glow when an output matches.
- Palette of 6 CSS variables; responsive; touch-friendly.
Features
- Drag-and-drop node placement and wiring with snapping and illegal-wire validation.
- Step, run, pause, and speed slider.
- Live inspector of wire symbols and node state.
- Rewindable execution trace.
- “Explain failure” panel showing the first mismatching output and its tick.
- Import/export a program as a compact base64 string.
- localStorage with try/catch and an in-memory fallback.
- Full keyboard operation.
- Respect prefers-reduced-motion.
